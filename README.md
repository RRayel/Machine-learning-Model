Feet to Meters Conversion Using TensorFlow
Overview

This project demonstrates a simple machine learning model using TensorFlow and Keras to learn the relationship between feet and meters. Instead of directly applying the known mathematical formula, the model learns the conversion factor through training data.

The neural network is trained on generated data where:

meters=feet×0.3048

After training, the model predicts meter values from new feet inputs and verifies how closely it learned the correct conversion factor.

Technologies Used

* Python 3

* NumPy

* Pandas

* TensorFlow

* Keras

Key Concepts Demonstrated

* Supervised learning

* Linear regression using neural networks

* Model training with TensorFlow/Keras

* Weights and bias optimization

* Mean Squared Error loss function
